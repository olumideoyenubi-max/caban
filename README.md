# Operation Dust Veil

A Call of Duty–style wave-survival first-person shooter that runs in the browser. It's one HTML file built on Three.js r128, which loads from cdnjs. Every sound is synthesised with WebAudio, so there are no asset files.

**Play:** open `index.html` in a desktop browser (or serve the folder, e.g. `npx serve .`) and click **Deploy**.

## Features
- Three weapons: the AR-7 full-auto carbine, the KS-12 pump shotgun (reloads shell by shell) and the LR-50 bolt-action marksman rifle with an 8× scope.
- Aim down sights, recoil, spread bloom, damage falloff, headshot multipliers, hitmarkers and tracers.
- Sprint, crouch, jump, frag grenades, and explosive barrels that can set each other off.
- Enemy soldiers that hunt you, take line-of-sight, strafe, fire in bursts and throw grenades from wave 2 onwards.
- Waves get bigger, and enemies get tougher and more accurate.
- Killstreaks: a UAV at 3 kills shows every hostile on the minimap, and an airstrike at 5 kills.
- CoD-style HUD: a rotating minimap, kill feed, damage direction indicators, grenade warning, health that regenerates when you avoid damage, and score popups.
- Touch controls: a virtual stick, drag to look, and on-screen buttons.
